# Модуль аналитических отчётов для АИС «Государственные программы»

Документация по разработке обособленного модуля **«Аналитические отчёты»** для АИС ГП (ASP.NET MVC 5, C#, Kendo UI).

## Задача

Сделать раздел с табличными и графическими аналитическими отчётами:

- **специалист** создаёт формы отчётов, и они автоматически заполняются данными системы;
- **пользователь** просматривает опубликованные формы и настраивает их представление под себя (столбцы, фильтры, сортировка, личные сохранённые виды);
- черновики форм видны только специалистам, неавторизованному пользователю отчёты недоступны;
- интерфейс на русском языке в стиле АИС ГП;
- диаграмма Маримекко — во второй очереди.

Исходного кода АИС ГП нет, поэтому модуль создаётся как самостоятельное приложение. Авторизация и исходные данные считаются реализованными в системе; для разработки и тестов используются тестовая база по модели данных и заглушка авторизации.
